# Project 7: PDI-12 Passive DI Box Manufacturing Proposal

## Overview
This repository contains the complete engineering report and manufacturing proposal for the PDI-12, a premium transformer-isolated passive Direct Injection (DI) box. The project includes electrical schematics, PCB layout verification, mechanical enclosure design, a full Bill of Materials (BOM) priced in ZAR, and strict First-Article Quality Assurance protocols. 

To provide the best review experience and demonstrate professional readiness, we have synthesized our KiCad engineering files, CAD mockups, and cost analysis into an interactive web presentation. 

## Project Deliverables
* **Interactive Web Pitch:** Click the link above to view the formatted proposal.
* **Manufacturing Proposal PDF:** The official document is available for download directly from the web presentation.
* **Engineering Files:** The complete KiCad project archive (schematics, PCB layout, Gerber files) can be downloaded via the website's project files link.
